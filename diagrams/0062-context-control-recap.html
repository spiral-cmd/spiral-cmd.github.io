04 / 05 · Key decisions confirmed

Decisions locked in v0.2-plan

A

Path A chosen — api.registerContextEngine()

Native plugin API, stable since OC 2026.3.7. Path B (embedded assemble/compact inside existing engine) is preserved only as Chunk 2's eviction heuristic for isolated crons — not a separate path.

R

raw.jsonl is append-only — never discarded

Consistent with real Hermes (Feb 2026) and lossless-claw 1.x. summary.md is a derived artifact with provenance link back to raw. MiroThinker safety guarantee: reasoning thread is never pruned.

L

Layer 1 assemble() ships independently (highest ROI)

Structured tool-output eviction on every model run with no LLM call. PRUNE_PROTECT = 40K tokens, PRUNE_MINIMUM = 20K tokens. Tombstones not silence — model always knows a prune happened and what exit code was.

C

Layer 2 compact() fires only at 85% context window

LLM-triggered summarization as a last resort, not a first step. Structured template output (Goal / Discoveries / Accomplished / Relevant files) — not a narrative blob. Fires only when Layer 1 cannot recover enough tokens.

P

Pilot on cato first — 7-day soak before fleet rollout

Cato is the lightest agent and lowest-risk pilot host. Measure RSS, context usage, task completion rate. Pass threshold = fleet rollout. Failure = iterate on plugin before touching heavier agents.
