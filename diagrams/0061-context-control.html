03 / 07 · Architecture

Per-session flat store + 2-layer pipeline

Per-session storage (one writer per session)
raw.jsonl

Append-only, never truncated. Source of truth. Full message history with tool calls and results.

summary.md

Derived artifact — provenance-linked back to raw.jsonl. Structured: Goal / Discoveries / Accomplished / Relevant files. Written by Layer 2 compact().

sticky.md

Zero-cost injection every turn. Goal · Constraints · Key Decisions · Open TODOs. Updated by heuristics, no LLM call. Prevents goal drift.

Two-layer pipeline

Layer 1 — assemble() · Chunk 2

Structured tool-output eviction on every model run. No LLM call. Protect 40K tokens of recent outputs, reclaim only if 20K+ available. Tombstones not silence.

Highest ROI — ships independently

Layer 2 — compact() · Chunk 3

LLM-triggered summarization only when Layer 1 insufficient. Structured template (not narrative blob). Updates summary.md with provenance link to raw.jsonl.

Fires at 85% context window

Key principle: Raw is append-only — never discarded. summary.md is a derived artifact. Consistent with real Hermes (Feb 2026) and lossless-claw 1.x best practice.

Path A · api.registerContextEngine() · stable since OC 2026.3.7

06 / 07 · Chunk -1 · Zero code
Chunk -1 · Zero code

Free wins before writing a line

1. lightContext: true

Skip workspace bootstrap file injection (AGENTS.md, SOUL.md, etc.) for isolated cron jobs that don't need them. Per-run token reduction with zero code. Config flip only.

Target: ~50 isolated crons

2. contextInjection:
"continuation-skip"

Skip re-injecting all bootstrap files on safe continuation turns. Only rebuild after heartbeats or compaction. Trims prompt size on the ~20 long interactive sessions specifically.

Target: interactive sessions

3. Janitor cron

deleteAfterRun: true has a confirmed reliability bug. Daily cleanup of stale isolated cron session files. 134 MB, 43 files identified 2026-09-18. One cron job, five minutes.

Biggest certain win in Chunk -1
